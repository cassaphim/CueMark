    Writing shortcuts

    Ctrl + O
    Open a text, Word, Pages or project file. Dropping a file on the window works too
    Right-click
    Add a new element, or change what the current line is
    Enter
    Start the element that usually comes next
    Tab
    Switch an empty line, or add the usual alternative
    Alt + 1 to 9
    Change the current line, in menu order
    int. or ext.
    Typed at the start of a line, becomes a scene heading
    (
    Typed first on a line inside a speech, becomes an acting direction
    Ctrl + B, I, U
    Bold, italic, underline. Shown as marks here, set properly on export
    Ctrl + Z
    Undo. Add Shift to redo
    Shift + right-click
    The browser's own menu, with spelling suggestions
