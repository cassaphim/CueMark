# CueMark updates

The first heading below is the current version. The app reads this file for its version number and its Version history window.

## 1.2.0 (2026-11-23)
- Open now reads Word (.docx), Apple Pages (.pages) and plain text files, and formats them into script elements as they come in
- Speakers found in an opened script are added to the cast and color tagged
- Opening a file can be undone, and a file can be dropped onto the window to open it
- Version number in the top bar, with this history behind it
- The downloaded app file carries its version in its name

## 1.1.0 (2026-11-23)
- Download software and Download script buttons, pinned to the top of the page area
- Published on GitHub at cassaphim.github.io/CueMark

## 1.0.0 (2026-11-22)
- First build: screenplay and stage play formats with a right-click menu for every element
- Cast of Characters page with a color for each character, marked through the script
- Scene index that builds itself, clean Courier PDF export, title page
